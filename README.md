# Wisdom School Fee Management Portal

Public school office and fee-management portal for Wisdom Nursery and Primary School.

Live website: https://msaterx22-sys.github.io/WNPSESSUR/

## Run Locally

**Prerequisites:** Node.js 20+


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build

`npm run build`

GitHub Pages is deployed automatically from the `main` branch through the workflow in `.github/workflows/deploy-pages.yml`.
